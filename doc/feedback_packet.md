# CM4向けfeedbackパケット

`Core/Src/ai_comm.c`の`sendRobotInfo()`は、G474の状態を128バイトのUARTフレームとして送信する。byte 0..1は同期値`AB EA`、byte 2はCRC-8/ATM、byte 3は最後に受けた制御指令の`check_counter`、byte 4..127は状態データである。

CRCは**byte 3..127の125バイト**をこの順序で計算する。パラメータは多項式`0x07`、初期値`0x00`、入力・出力のビット反転なし、最終XOR`0x00`。byte 0..2は計算対象に含めない。標準検査文字列`123456789`のCRCは`0xF4`となる。

G474は全フィールドを詰めた後、DMA送信前にCRCをbyte 2へ書く。受信側はフレーム長、同期値、CRCを確認してから状態値を採用する。FWゲートウェイ応答などでbyte 112..126を上書きした場合も、上書き後のバイト列でCRCを計算する。

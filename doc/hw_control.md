# Orion ハードウェア制御
## アクチュエーター
4輪オムニホイール､ドリブラーモーター､キッカー(チップ､ストレート)を備える｡

## センサー
各オムニホイールにモーター､オンボードのIMU､ボール接触判定用のボールセンサー
ほかは温度･電圧･電流などの内界センサーを備える｡

# モーター制御
## オムニホイール
オムニホイール配置は前方が120度開いた変則配置の4輪オムニホイールになっている｡  
右前がID0,右後ろがID1,左後ろがID2,左前がID3と時計回りに割り振らてている｡  

## 速度制御
各モーターには回転数で指示をするが､"無負荷時にその回転数になる電圧で出力"であって､フィードバック制御が必要となる｡  
指令速度まで設定された加速度で追従する｡内部の目標速度値があり､その内部目標速度を設定加速度で変動させる｡  
内部目標速度に追従するように､各モーターの出力を制御する｡  
各モーターは､各モーターでの目標角度を持ち､内部目標速度を分解して各モーターの目標角度変化量に割り当てる｡

## ヨー角度制御
内部IMUと､外部カメラ情報を組み合わせて機体のヨー角度を制御する｡  
目標角度への追従は､目標角度に対して滑らかに追従するため､加速度を考慮した目標速度制御を行っている他､振動を防ぐために一定のスレッショルドを持たせている｡  
モーター制御としては､各モーターの目標角度変化だけでは追従性が足りないため､各モーター目標角度+微分項を別途渡すことで実現している｡
